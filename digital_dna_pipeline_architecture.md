## Как openness_type меняет стратегию интервью

### Тип А · Открытый (score 70–100)
```
Этап 1 (6 уровней)    → детальные развёрнутые ответы
Этап 2 (открытость)   → сразу определена как высокая
Этап 5 (интервью)     → начинаем с Уровня 2 (Зеркало)
                         быстро переходим к Уровню 3 (Тень)
                         15 вопросов → 85% матрицы
```

### Тип Б · Осторожный (score 40–69)
```
Этап 1 (6 уровней)    → краткие, аккуратные ответы
Этап 2 (открытость)   → средняя, нужна разминка
Этап 5 (интервью)     → начинаем с Уровня 1 (Метафора)
                         зеркало — только когда openness вырастет
                         20 вопросов → 70–80% матрицы
```

### Тип В · Закрытый (score 0–39)
```
Этап 1 (6 уровней)    → минимальные ответы, всё «правильно»
Этап 2 (открытость)   → низкая, нужен долгий разогрев
Этап 5 (интервью)     → начинаем с Уровня 0 (Наблюдение)
                         не торопимся, ждём сигналов
                         25+ вопросов → 60–70% матрицы
                         Living Profile заполнит остальное
```

## Пример: как «крючок» ведёт вопросы

```
Вопрос (уровень 1):
«Что ты делаешь когда хочешь полностью выключить голову?»

Ответ:
«Еду на машине без цели. Музыка — и всё.»

Система извлекает:
  крючок_1: «без цели»           → отношение к контролю / свободе
  крючок_2: [отсутствие людей]   → одиночество как ресурс?
  вектор_активирован: V10, V12
  пробел_следующий: V18 (время), V23 (состояния)
  openness_delta: +3 (ответил просто, без защиты)

Следующий вопрос (уровень 1→2, крючок «без цели»):
«Я сам замечаю что мне нужны моменты когда нет никакой задачи —
 иначе теряю что-то важное. У тебя "без цели" — это отдых
 или что-то чего тебе не хватает в обычной жизни?»

Ответ:
«Скорее второе. В обычной жизни я всегда что-то должен...»

Система:
  крючок: «всегда что-то должен»  → долженствование / роли / V04, V05
  напряжение: V03 (достижения) высок + V23 (состояния) — истощение
  openness_delta: +8 (раскрыл внутренний конфликт)
  → повышаем уровень до 2

Следующий вопрос (уровень 2, крючок «должен»):
«У меня была полоса когда я понял что живу чужим расписанием —
 выполняю, но не выбираю. Было у тебя ощущение что "должен"
 стало больше чем "хочу"? И как долго это длилось?»
```

## Данные для реализации

### Структура состояния интервью
```javascript
InterviewState = {
  // Этап 0-1: вводные
  basicData: { name, age, city, profession, selfDescription },
  levelData: { L0, L1, L2, L3, L4, L5 },

  // Этап 2: открытость
  openness_score: 0–100,
  openness_type: 'A' | 'B' | 'C',
  openness_level: 0–3,      // текущая разрешённая глубина

  // Этап 3-4: кристаллы и векторы
  crystals: { C1..C9 },     // 0–1 после анализа 6 уровней
  matrix: number[24][9],    // заполняется в процессе интервью

  // Этап 5: адаптивное интервью
  answer_history: Answer[],
  active_vectors: string[],
  gap_vectors: string[],
  tension_zones: [string, string][],
  last_hook: string,
  questions_asked: number,

  // Результат
  personality_signature: string,
  dna_completeness: 0–100   // % заполненности матрицы
}
```

### Приоритет выбора следующей темы
1. Зона напряжения (противоречие между активными векторами)
   → самые ценные данные для ДНК
2. Критический пробел (вектор не покрыт ни одним ответом)
   → необходимые данные
3. Углубление текущей темы (крючок из последнего ответа)
   → уточнение уже активных векторов
4. Новый блок (если пробелов нет, открываем новую тему)
   → расширение покрытия

## 🧠 Интеграция когнитивного контроля в пайплайн

В процессе генерации вопросов и калибровки ДНК активно участвуют специализированные когнитивные контуры:

1. **Pre-mortem Agent (Симуляция сбоев):**
   * Перед тем как задать пользователю следующий вопрос на этапе 5, агент симулирует потенциальные когнитивные искажения (например, сопротивление эго, социальную желательность ответов) и технические ошибки интерпретации.
   * Если симуляция выявляет риск искажения данных, формулировка вопроса автоматически корректируется в сторону более безопасной/проективной (например, переход от прямого вопроса на уровень метафоры).

2. **Metacognition Monitor (Метакогнитивный контроль):**
   * Для каждой заполненной ячейки матрицы `Matrix[24][9]` вычисляется коэффициент уверенности $C_{conf} \in [0, 1]$.
   * Если по итогам 20 вопросов средняя уверенность по ключевым векторам личности $< 0.8$, Metacognition Monitor блокирует фиксацию ДНК и инициирует фазу уточняющего интервью (зону ближайшего развития), запрашивая разъяснения по спорным точкам.

3. **Биоэтический предохранитель:**
   * Программное ограничение в Master Agent, запрещающее автоматическую перезапись или сглаживание уникальных "эмоциональных шрамов" и базовых черт характера в цифровой ДНК. Любое глубокое изменение структуры допускается только при согласовании с оригиналом и верификации со стороны Metacognition Monitor.
